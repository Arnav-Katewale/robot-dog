Sonar Echo divider

The HC-SR04 sends back 5 V, but Pi pins only take 3.3 V. Three 1 kΩ resistors drop it to a safe 3.3 V.

Echo ──[1 kΩ]──┬──► pin 18 (GPIO24)
               │
            [1 kΩ]
            [1 kΩ]   (two in a row = 2 kΩ)
               │
              GND (pin 14)

5 V × 2 ÷ 3 = 3.33 V at the pin

Servo ID plan

  • IDs 1–4 are already set on your four servos. Use them for the front legs.
  • New LX-16A servos arrive set to ID 1. Plug them in one at a time and give each its new ID (5, 6, 7, 8, 9) before adding the next.
  • Label each servo with its ID on tape. It saves a lot of confusion later.
  • Hip = the joint where the leg meets the body. Knee = the middle of the leg.

Safety rules

  1. Never plug the Pi's USB-C power in while the UBEC is connected. Two supplies on the Pi at once can damage it. On the bench, use one or the other.
  2. Before the UBEC touches the Pi, measure its output: it must read about 5 V. Some UBECs have a 5 V / 6 V jumper; make sure it is set to 5 V.
  3. Double-check pins 2 and 6 before powering up. 5 V on a wrong pin can kill the Pi.
  4. A full 2S battery is 8.4 V, which is the LX-16A's top limit. Don't use a 3S (11.1 V) battery.
  5. When the Pi runs from the UBEC it may show a "low power" warning. That's expected here; we'll set one config line to quiet it when we set up the Pi.
